# Muhammad Osama Amin — public portfolio

A responsive, accessible, dependency-free portfolio for applied AI and cloud engineering.

Live: https://vmnebula.github.io/osama-amin-portfolio/

## Development

No package installation or compilation is required. GitHub Pages publishes the static files directly from the root of `main`, using the repository's established Pages build and deployment workflow.

- `index.html` and `styles.css`: portfolio
- `resume.md`: public résumé source
- `resume.html`: print-friendly version
- `Muhammad_Osama_Amin_CV_Tech.pdf`: sanitised downloadable public résumé

Run `python3 -m unittest discover -s tests -v` for static content, privacy, and link checks. Preview with `python3 -m http.server 8080`. Test desktop and mobile layouts before publishing.

Keep all public résumé versions in sync. Do not publish personal phone numbers, identity documents, home addresses, credentials, client data, confidential funding information, or unsupported performance metrics. Founder programme participation is separate from investment. Recognition must distinguish finalist status from winning; the Wafi Tameer 2026 entry is supported by awards-team correspondence supplied by the founder, not an independently authenticated public finalist directory.

This is a static site: no tracking, third-party scripts, WebGL, external fonts, or animation loops.
